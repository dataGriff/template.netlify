🐍 slopstopper-cli

MIT

The Python package every check, report and PR comment goes through. Quick standalone try: pipx install slopstopper-cli; in an adopting repo it's pinned in mise.toml and installed via mise. See the latest release for changelog and signed artifacts.

CLI surface 
slopstopper checks list                       # see what's available
slopstopper doctor                            # verify external tools
slopstopper run hygiene:docs-size             # run a check (writes .ss/reports/...)
slopstopper emit hygiene:docs-size --target pr-comment
slopstopper templates eject playwright.config.js
slopstopper serve                              # bundled static server

Bare slopstopper prints a command grid + Quick-start block. Every subcommand has examples in --help.

📋 Task

MIT

task ss:* is the canonical interface — humans, agents and CI all invoke checks through it. Adopters get one consistent invocation surface across the suite and the rest of their codebase. Re-run install.sh with --no-task to skip Task entirely; workflows will call the CLI directly.

Taskfile excerpt 
tasks:
  hygiene:docs-size:
    cmds: [slopstopper run hygiene:docs-size]
  reliability:accessibility:
    cmds: [slopstopper run reliability:accessibility -- "{{.CLI_ARGS}}"]

Run from your repo with task ss:hygiene:docs-size, task ss:reliability:accessibility -- https://example.com, etc.

🪝 Git hooks

GPL-2.0

install.sh wires a pre-push hook via core.hooksPath that runs the fast hygiene checks (task ss:hygiene:test) before every push — so the first CI run confirms rather than discovers. Only the static hygiene subset runs locally; the server/browser checks stay in CI. It won't override an existing husky / lefthook / pre-commit setup — re-run install.sh --no-hooks to skip it, or bypass a single push with git push --no-verify.

.githooks/pre-push (installed) 
# Runs through `mise exec` — git hooks don't source your shell profile.
exec mise exec -- task ss:hygiene:test

Same command the hook, your local loop and CI all run — one invocation surface.

📄 llms.txt Check

MIT

Audits your site's /llms.txt — the llmstxt.org convention, a curated markdown map that lets AI assistants read your key content without parsing HTML. Asserts an H1 title, a summary blockquote and markdown links to key content, and can HEAD-verify every link resolves. Stdlib Python — no new dependencies.

Learn more about llms.txt check config →
Taskfile excerpt 
reliability:llms-txt:
  desc: Validate the llms.txt AI-discoverability map on a live URL
  cmds:

  # Env: LLMS_TXT_TEST_URL, LLMS_TXT_PATH (default /llms.txt)
  # Config: reliability.llms_txt.{check_links, require_summary}

🤖 robots.txt Check

MIT

Audits your site's /robots.txt for the two failures Lighthouse buries. Its headline job is the de-index guard: a stray Disallow: / under User-agent: * silently removes the whole site from search. Also requires a Sitemap: pointer, treats an Llms: pointer as advisory, and can HEAD-verify the referenced URLs resolve. Stdlib Python — no new dependencies.

Learn more about robots.txt check config →
Taskfile excerpt 
reliability:robots-txt:
  desc: Audit robots.txt for discoverability + accidental de-indexing on a live URL
  cmds:
    - slopstopper run reliability:robots-txt -- {{.CLI_ARGS}}
  # Env: ROBOTS_TXT_TEST_URL, ROBOTS_TXT_PATH (default /robots.txt)
  # Config: reliability.robots_txt.{allow_disallow_all, require_llms, check_links}

🗺️ sitemap Check

MIT

Crawls your site from / and cross-checks the served sitemap.xml against the pages it actually reaches. A reachable page missing from the sitemap, or a <loc> that 404s, hard-fails — that's drift. llms.txt gaps are advisory. Flat and nested (sitemap-index) shapes both pass. When it fails it recommends generating the file from your routes so it can't drift. Stdlib Python — no new dependencies.

Learn more about sitemap check config →
Taskfile excerpt 
reliability:sitemap:
  desc: Audit sitemap.xml completeness + drift by crawling a live URL
  cmds:
    - slopstopper run reliability:sitemap -- {{.CLI_ARGS}}
  # Env: SITEMAP_TEST_URL, SITEMAP_PATH (default /sitemap.xml)
  # Config: reliability.sitemap.{max_pages, ignore_paths, allow_orphans,
  #         require_llms_complete, sitemap_path, llms_path}
